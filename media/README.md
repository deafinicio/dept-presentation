# Фотографії для презентації

Завантажте фото в цю папку гілки main. Підтримуються .jpg, .jpeg, .png і .webp у нижньому регістрі. Один файл на базову назву, наприклад educational-comic.jpg.

| Базова назва | Після якого слайда відкривається фото |
| --- | --- |
| session-overview | Два напрями роботи |
| session-in-play | Діти вчаться через гру |
| teen-session | Сесії для підлітків |
| youth-session | Сесії для молоді |
| adult-session | Сесії для дорослих |
| vartovi-presentation | Демонстрація розмальовки «Вартові дивосвіту» |
| vartovi-cover, vartovi-page | «Вартові дивосвіту», спочатку обкладинка, потім сторінка |
| educational-comic | Комікси для бібліотеки |
| board-games, game-material | Пазли й настільні ігри |
| vr-game, vr-route | Навчальна VR-гра, спочатку плакат, потім маршрут у парку |

Після публікації через GitHub Actions перше зображення з’являється на відповідному слайді. Кожне додане фото також автоматично отримує окремий повноекранний крок у вихідних пропорціях. «Вперед» відкриває наступне фото або переходить далі, «Назад» повертає на попередній крок. За відсутності фото на слайді залишається ілюстрація, а крок збільшення пропускається.

Погоджені контакти у contact.json (email, phone, url) з’являться на останньому слайді.
