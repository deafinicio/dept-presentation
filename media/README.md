# Фотографії та контакти

Завантажте файли в цю папку, зберігши одну з наведених базових назв. Працюють розширення `.jpg`, `.jpeg`, `.png` та `.webp` у нижньому регістрі. Для кожного місця завантажуйте один файл.

| Базова назва | Де з’явиться |
| --- | --- |
| `session-overview` | 1. Початок, загальний кадр заняття |
| `session-in-play` | 3. Ігрова сесія, діти в процесі гри |
| `game-material` | 4. Гра наживо, матеріал крупним планом |
| `vartovi-cover` | 5. Матеріали, обкладинка «Вартових дивосвіту» |
| `vartovi-page` | 5. Матеріали, одна сторінка розмальовки |

Наприклад, `media/session-in-play.jpg`. Фото показуються повністю, без обрізання. Для перегляду деталей відкрийте «Збільшити». Порожні місця залишаються нейтральними рамками.

У `contact.json` можна вказати погоджені контакти для фінального слайда: `email`, `phone`, `url`. Порожні поля не показуються. Після коміту в `main` зміни публікуються через GitHub Actions.
