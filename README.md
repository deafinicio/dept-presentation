# Виховна година, якої ще немає в розкладі

Робочий інтерактивний макет для Відділу протимінної діяльності Харківської обласної організації ТЧХУ.

- **Перегляд.** Відкрийте `index.html` у браузері. Файл самодостатній, працює локально й без підключення до інтернету. Сцена автоматично обирає WebGL або запасний режим Canvas.
- **Для GitHub Pages.** Готовий `index.html` можна покласти у корінь статичного сайту. Для відтворення збірки запустіть `npm ci` та `npm run build`. Збірка пише у `dist/index.html`.
- **Редагування.** `app.js` містить текст і стан семи етапів. `desk.js` містить координати, камери, процедурні моделі, текстури та рухи. `software.js` відтворює просту геометрію макета через Canvas, коли WebGL недоступний. `index.template.html` містить розмітку й оформлення.
- **Підключення майбутніх моделей.** Окремо від контенту замініть процедурні вузли в `desk.js` моделлю GLB через Three.js GLTFLoader. Почніть із кореня сцени, розкладу, картки вправи й шарніра ноутбука. Збережіть точки прив’язки картки та екрана. Запасний Canvas наразі розрахований на прості моделі макета. Для довільного GLB збережіть процедурний запасний варіант або підготуйте окремий.
- **Графіка і контакти.** Фото, оформлення друкованого матеріалу й контакти мають бути підставлені з погоджених матеріалів. Макет створює лише чернетку звернення для копіювання.
