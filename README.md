# Відділ протимінної діяльності · Харківщина

Вебпрезентація для закладів освіти. Чотири фізичні стенди у Three.js об’єднують слайди про відділ, аудиторії, інструменти й співпрацю. У браузерах без WebGL2 працює програмна проєкція тих самих моделей.

Клікер, Page Down / Page Up і стрілки проходять усі кроки вперед і назад. Мапа та кожна наявна фотографія мають власний крок. Наступне натискання закриває перегляд і продовжує показ. Escape повертає до пояснення. Home та End ведуть на початок і в кінець.

На GitHub Pages презентація вбудовує [живу мапу відділу](https://deafinicio.github.io/mine-risk-map/) зі збереженням керування клікером. Зведення за трьома звітними локаціями доступне окремо й працює офлайн. Показник за локацією включає навколишні громади. Статистика та контур області у report.json підготовлені з [публічного зведення за січень–жовтень 2026](https://github.com/deafinicio/mine-risk-map/blob/0f2f7813c383b045e162575bc866648aabd888b6/data/dashboard-2026.json) та kharkiv_poly.geojson тієї ж ревізії.

Тексти й порядок сторінок — exhibits.js. [Як додати фото та контакти](media/README.md).

Локальна збірка: npm ci, потім npm run build. GitHub Actions публікує dist/ із main. Кореневий index.html є автономною збіркою; для показу з фотографіями збережіть поруч папку media/.
