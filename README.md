# Як ми говоримо з дошкільнятами про мінну небезпеку

Тривимірна вебпрезентація Відділу протимінної діяльності Харківської обласної організації ТЧХУ для працівників закладів дошкільної освіти.

[Відкрити презентацію](https://deafinicio.github.io/dept-presentation/)

- Клікер або стрілки клавіатури ведуть за маршрутом «стенд → опис → наступний стенд». У зворотному напрямку маршрут той самий. Кнопка «Загальний план» відкриває всю 3D-фотострічку. Меню внизу відкриває вибраний стенд.
- [Додати фото й контакти](media/README.md). GitHub Actions збирає та публікує зміни з гілки `main`.
- Для локальної збірки запустіть `npm ci` та `npm run build`. Результат у папці `dist`. За відсутності фото `dist/index.html` можна відкрити окремо. З фото відкривайте його разом із папкою `dist/media`.
